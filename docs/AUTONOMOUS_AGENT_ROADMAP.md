## 当前边界与后续工作

- **原子岛**：本地协议字段和进度入口已实现，正式 VPush SDK 接入、获批场景及原子岛展示尚未完成。平台步骤与所需应用配置见 [原子通知](VIVO_ATOMIC_NOTIFICATIONS.md)。普通通知独立可用。
- **熄屏**：独立用户开关、按运行申请、局部唤醒锁和 Root helper 生命周期已实现；真实熄屏持续操作仍需专项真机验证，默认关闭。
- **应用兼容**：虚拟屏没有 Unicode 输入或无障碍树，拒绝已有任务、不能缩放及特殊启动模式。未验证任意应用、多用户和其他 ROM。
- **vivo 数据源**：录音摘要状态语义、AI Engine 加密个人索引和账单尚未适配；不读取聊天数据库替代系统记忆，也不尝试解密。
- **触发器**：定位、日历临近、文件、共享内容与系统记忆更新仍未实现；候选设计和权限要求列在自动任务文档。
- **调度精度**：OriginOS 的冻结及系统时间控制可能延后唤醒，定时任务不是准点闹钟。已增加持久化 JobScheduler 时间唤醒及 deadline 检查；离线和前台忙碌时等待，不重放中断操作。

## 验证方式

运行 `./gradlew :app:testDebugUnitTest`、`:app:assembleDebug`、`:app:assembleRelease` 和 `:app:lintDebug`。自动化测试覆盖迁移、时区/DST、去重、冷却、运行次数、中断恢复、版本冲突、复盘权限名单和技能资源保留。

本次全量 JVM 验证共 1514 项用例，0 失败、0 错误、2 项既有跳过；Debug 与 R8 Release APK 均已生成。Lint 剩余 4 项既有错误：`NativeSystemOperations.kt` 的 3 项电话权限检查，以及 `build.gradle.kts` 的高版本号；新增代码没有 Lint 错误。

真机为 vivo X200 Pro mini V2419A，Android 16 / OriginOS 6 `PD2419B_A_16.1.12.38.W10`，KernelSU 与 LSPosed。开发验证使用本机模拟服务和专用标记，不调用付费模型；测试记忆哈希恢复、临时技能删除及原模型选择恢复均确认通过。测试 APK、日志、截图和私有数据不进入 Git。
